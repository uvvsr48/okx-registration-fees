## 现货 vs 合约：选哪个、怎么用

OKX 的核心交易场景就是现货和合约两类，新手和老手的用法差别很大。

**现货**就是直接买卖币，BTC/USDT、ETH/USDT 这类交易对，买了币就是你的，可以提到自己的钱包。基础费率 Maker 0.08% / Taker 0.10%，适合囤币、定投、长线持有。

**合约**分永续合约和交割合约，本质是带杠杆的衍生品。基础费率 Maker 0.02% / Taker 0.05%，比现货低很多，但杠杆放大了盈亏。OKX 合约支持全仓和逐仓两种模式：

- 全仓：账户内所有同币种资产都作为保证金，抗波动能力强，但爆仓会牵连整个账户
- 逐仓：只有开仓时锁定的那部分保证金承担风险，爆仓只损失该仓位

杠杆倍数可以在开仓前调整，路径是 App → 交易 → 合约 → 选择币对 → 杠杆选项。新手建议从低杠杆（3x–5x）和逐仓模式开始，别一上来就全仓高杠杆。

> 合约不是"赚快钱"的工具。杠杆放大的是波动，不是方向判断的正确率。判断错了，10x 杠杆意味着 10% 的反向波动就接近爆仓。

## 跟单与策略交易：不想盯盘的替代方案

如果你不想自己盯盘，OKX 提供两类自动化工具。

**跟单交易**：跟随平台上的精英交易员，他们的开仓平仓会按比例复制到你的账户。OKX 对交易员有等级体系，带单资产 500 USDT 以上即可参与，达到 100,000 USDT 带单资产可享更高分润。跟单的好处是不用自己分析，坏处是交易员也会亏，且分润会吃掉一部分收益。

**策略交易（交易机器人）**：包括现货网格、合约网格、天地网格、宽幅震荡网格、定投等。网格策略的核心是在设定的价格区间内自动低买高卖，适合震荡行情。天地网格区间更宽，交易频率更低，适合捕捉大波动。定投则是按固定金额定期买入，平滑成本。

这些工具的入口都在 App 的"策略&跟单"板块，不需要额外下载插件。

## 赚币理财：闲币怎么生息

OKX 的"赚币"模块把理财分成了几条线：

- **简单赚币**：本质是平台把你的币出借给机构或用户，利息的 85% 分给用户，平台收 15%。按小时结算，活期可随时赎回。适合放 USDT、BTC 这类长期持有的币种。
- **链上赚币**：直接参与链上 DeFi 协议的质押或流动性挖矿，APY 已包含所有费用，没有隐藏收费。收益更高，但需要理解链上风险。
- **稳定币生息宝、双币赢、BTC 屯币生息宝**：分别针对稳定币、结构化产品、BTC 长线持有者的不同理财方案，收益率和锁仓期各不相同。

新手从简单赚币活期开始最稳妥，看懂机制再考虑链上赚币或结构化产品。

## 出入金：C2C 买币与网络选择

OKX 的入金主流方式是 C2C（个人对个人）交易，支持微信、支付宝、银行卡等支付方式。前提是已完成基础身份认证，否则无法操作。

**充币（从其他钱包或交易所转入）**的关键是选对网络。以 USDT 为例：

- USDT-Tron（TRC20）：速度快、手续费低，适合小额
- USDT-Ethereum（ERC20）：更安全，但到账慢、手续费高

充错网络是新手最常见的资产损失原因，转账前务必核对币种和网络是否一致。

**提币**到账时间取决于区块链确认速度，一般由网络矿工费决定，费越高确认越快。提币记录里可以查看交易 ID 和区块链状态，长时间未到账多半是区块确认延迟。
